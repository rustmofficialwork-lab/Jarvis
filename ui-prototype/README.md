# JARVIS UI Prototype

A standalone, image-free HTML/CSS/JavaScript interface concept for review.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Notes

- This is an isolated prototype branch and does not change the Windows desktop app.
- Clock and chat interactions work in the browser.
- Hardware metrics and module states are illustrative demo values, not live telemetry.
- No generated concept image or image background is used.
